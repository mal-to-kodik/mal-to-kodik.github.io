# What's this?

A clean page to watch a [MyAnimeList](https://myanimelist.net/) anime via Kodik player.

# How to use it?

Submit an anime id or URL through [the form](https://mal-to-kodik.github.io/)

# How to get an anime id?

An anime's URL contains an id.

For example, `1` from `https://myanimelist.net/anime/1/Cowboy_Bebop`
